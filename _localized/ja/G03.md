**何度もいきんで尿がほとんど、または全く出ない場合、あるいは繰り返す排尿の試みで尿が出ているか分からない場合は、直ちに獣医師の診察が必要です。今すぐかかりつけの獣医師か救急動物病院へ連絡してください。** 閉塞の可能性は緊急事態です。採尿や日誌の完成のために受診を待たないでください。 [Cornellの尿路の健康に関する案内](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/feline-lower-urinary-tract-disease)

診察を受けた後も、用語は分かりにくいかもしれません。自分では尿路感染だと思っていても、退院時の書類には膀胱炎、結晶、FLUTDと書かれていることがあります。これらは違うものを指します。最初に役立つ質問は、**「何が見つかり、今は何が症状の原因だと考えられ、何がまだ不明ですか」**です。

## 原因を表している言葉はどれか

血尿、頻繁なトイレ通い、家の中での粗相は、報告すべき症状です。複数の状態で起こり得るため、見た目だけでは病気を特定できません。 [Cornellによる排尿症状の解説](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/feline-lower-urinary-tract-disease)

| 記録にある言葉 | 分かりやすい意味 |
|---|---|
| **FLUTD** | 猫下部尿路疾患。膀胱と尿道の疾患をまとめた呼び方で、一つの根本原因を表すものではありません。 |
| **膀胱炎** | 膀胱の炎症。この言葉だけで細菌感染を意味するわけではありません。 |
| **FIC** | 猫特発性膀胱炎。他の原因を検討し除外した後に診断する、痛みを伴う状態。 |
| **細菌性尿路感染** | 尿路の細菌感染。細菌性膀胱炎では膀胱が関わります。 |
| **結晶尿** | 尿の検体に結晶が見られること。 |
| **尿路結石** | 尿路の石。固まったミネラルの形成物。 |
| **尿道閉塞** | 正常な尿の流れを妨げる詰まり。緊急事態です。 |

これらの区別は[2025年のiCatCare診断ガイドライン](https://pmc.ncbi.nlm.nih.gov/articles/PMC11816079/)に沿っています。結晶という所見とFICという作業診断が同じ記録に載ることもあります。今回、それらがどう関係すると獣医師が考えているかを尋ねてください。

## 各検査は何を明らかにしようとしているか

検査は個々の猫に合わせて選ばれます。以下は計画を理解するための一覧で、すべての猫に必要な検査のリストではありません。Cornellは身体診察と尿検査、必要に応じた他の検査を説明しています。 [Cornellの診断の概要](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/feline-lower-urinary-tract-disease)

| 検査 | 目的と役立つ質問 | 確認したい限界 |
|---|---|---|
| 身体診察と病歴 | 「今必要な対応は何で、どの原因を調べていますか」 | まだどの検査が必要か。 |
| 尿検査 | 尿の濃さ、化学的性質、顕微鏡所見を調べます。「何が分かりましたか」 | 細菌培養と同じではありません。 |
| 培養と薬剤感受性検査 | 細菌の増殖を調べ、必要な場合に抗菌薬の選択に役立てます。「症状とどう関係しますか」 | 採取方法と臨床状況が解釈に影響します。 |
| X線または超音波 | 結石や構造の変化を調べます。「この検査では何を評価しましたか」 | 検査ごとに得られる情報が異なります。 |
| 血液検査 | 腎機能や、診療に影響する別の健康上の問題を確認します。 | 血液検査ですべての膀胱の問題に名前が付くわけではありません。 |

培養との違いは[ISCAIDの感染症ガイドライン](https://doi.org/10.1016/j.tvjl.2019.02.008)で説明されています。報告書の写しとともに、分かりやすい言葉で結果を聞いてください。「正常」は、どの疑問に答えた検査かが分かると、より役立ちます。

## 「FICの疑い」は検査の失敗を意味するか

FICを単独で確定する、臨床で利用可能な検査はありません。病歴、所見、他の原因の除外を組み合わせて診断します。作業診断は、不確かさを残しつつ、現時点で最もよい説明を示すものです。痛みが気のせいだとか、飼い主がストレスの出来事を見逃したという意味ではありません。 [2025年のiCatCareガイドライン](https://pmc.ncbi.nlm.nih.gov/articles/PMC11816079/)

「FICと考える確信はどの程度で、どんな結果や変化があれば考え直しますか」と尋ねてみてください。症状が戻った場合は以前の記録を持参します。以前の診断名は役立つ背景であり、今も当てはまると飼い主が証明する必要はありません。

## 結晶があれば結石があると証明できるか

できません。結晶が見つかっても、詰まりを起こす結石があるとは限りません。尿中に対応する結晶がなくても結石は起こり得ます。 [2025年のiCatCareガイドライン](https://pmc.ncbi.nlm.nih.gov/articles/PMC11816079/)

検体の扱いも重要です。**尿路疾患の既往がない猫41頭**の尿を使った実験では、分けた検体を保存することで、結晶の検出が変化しました。これは検体の解釈に関する所見であり、食事が病気を防ぐことを示すものではありません。 [Sturgessら、2001年](https://pubmed.ncbi.nlm.nih.gov/11876621/)

「結石は見つかりましたか、疑われていますか。この結晶は今回の症状に関係すると考えられますか。治療目標を確かめるには何を追跡しますか」といった質問が役立ちます。

## 細菌が増えたら必ず抗菌薬が必要か

感染に起因する症状がなくても細菌が存在することがあります。これを**無症候性細菌尿**と呼び、通常は抗菌薬による治療を勧めません。例外には臨床的判断が必要です。したがって培養陽性は解釈が必要で、飼い主が自動的に治療を決めるものではありません。 [ISCAIDガイドライン](https://doi.org/10.1016/j.tvjl.2019.02.008)

「尿路感染」が繰り返す場合は、感染が確認されたのか、どう採尿したのか、さらに調べる必要があるのかを尋ねてください。薬の変更は処方した獣医師と話し合う内容です。

帰る前に、作業診断、確認された所見、結果待ちの項目、今後の計画を書き留めてください。[受診記録用紙](/learn/cats/urinary-health/vet-visit-record/)には、情報をまとめる欄があります。最後に「どんな変化があれば直ちに連絡すべきですか」と確認しましょう。飼い主の役割は観察を明確に伝えること、診療チームの役割はそれを解釈することです。
